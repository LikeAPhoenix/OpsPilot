# 1. 背景（Why）

当前 OpsPilot 后端功能已相对完备（支持流式对话、统一鉴权、Milvus 知识库检索、AIOps 告警分析），但缺乏一个与之匹配的现代化、高可用的前端界面。原有的前端已不能满足诸如多页面路由、流式事件（SSE）稳定处理、专属 AIOps 结论呈现以及稳定的会话（Session ID）持久化管理的需求，亟需进行一次全面的前端原生 JS + Vite 架构重构。

# 2. 目标（What，必须可验证）

- [x] 基于 HTML/CSS/Vanilla JS 和 Vite 构建前端多页应用（登录页、主工作台页）。
- [x] 实现 JWT Token 的全局拦截自动注入与 401 失败登出。
- [x] 构建稳定、能正确分离系统事件与消息载体的服务器推送事件（SSE）原生解析能力。
- [x] 搭建本地的会话存储体系，并在前端 URL 中将 `session_id` 状态实体化。
- [x] 提供独立的、“零打断”的只读 AIOps 告警分析专属会话展示能力。

# 3. 非目标（Explicitly Out of Scope）

- 不对后端已有 API（如 `/api/chat`, `/api/ai_ops` 等）的出入参结构做修改。
- 不引入重型前端视图框架（如 React / Vue）。
- 不把大模型的 AIOps 分析长报告注入到普通的问答大模型上下文中去消耗 Token。

# 4. 使用场景 / 用户路径

1. **登录与鉴权**：用户访问页面被拦截跳转至 `login.html`，输入凭证登录返回后获颁 Token 存储本地，再自动跳回主程序。
2. **多会话管理**：用户可在侧边栏点击历史对话进行无缝切换（URL 参数随之改变），或者新建对话；切换时会重新挂载聊天上下文。
3. **沉浸式对话**：用户在输入框键入并发送问题，收到大模型打字机式的流式 Markdown 响应并高亮代码块。
4. **智能告警排查**：运维人员点击页面右上角“AIOps 分析”按钮，主视图锁定并创建一条不可在底层追问的新“AIOps 报告”专用只读会话，等待分析动画结束后即呈览深度告警推演图谱。

# 5. 功能需求清单（Checklist）

- [x] Axios 网络请求封装与拦截器支持。
- [x] Auth JS（注册/登录实现）。
- [x] Chat JS（负责气泡渲染、Markdown 转化及 `highlight.js` 行内高亮）。
- [x] 流式（SSE）`fetch` 解析引擎的健壮性设计（跳过 `.isDone` 和系统级 `event: connected` 通知）。
- [x] AIOps 专用只读会话页支持（隔离普通对话与报告展示区的交互输入权）。

# 6. 约束条件（非常关键）

- 技术约束：强依赖于现代浏览器的特性（如 `fetch ReadableStream`），构建工具限定为 `Vite` 构建。
- 架构约束：遵守前后端彻底分离架构。API 采用反向代理接入（跨域交由 Vite 解决）。
- UI 约束：严格采取 Glassmorphism 暗黑系毛玻璃主题设计，提供高级的视觉美学体感。

# 7. 可修改 / 不可修改项

- ❌ 不可修改：服务端路由树和 JWT 签发验证逻辑。
- ✅ 可调整：前端 JS 的事件绑定位置、LocalStorage 的 `Keys` 拼写规则。

# 8. 接口与数据约定（如适用）

- `/api/chat_stream` 请求体 `{"Id": "", "Question": ""}`。在第一次请求时 `Id` 需留空由后端发放并在前端的 `event: session` 回收。
- 发送前必须携带 Header：`Authorization: Bearer <TOKEN>`。
- `/api/ai_ops` 为长耗时 POST 请求（无长连接）。由于后端执行耗时较长，前端 Axios 超时必须配在 300s 以上。

# 9. 验收标准（Acceptance Criteria）

- 如果用户点击左下角历史，则中间对话区域必须无闪缩加载对应的历史气泡数组，且 URL 更新为 `?session_id=XXX`。
- 如果用户新建 AIOps 分析，则必须生成一条名为 `AIOps报告: <当前时间>` 的历史，并在页面正文区域出现骨架屏直到接收到报告数据；且此时界面底部输入框应当被完全隐藏（`display:none`）。
- 如果后端进行 SSE 握手传递 `event: connected` 事件，则页面不得因解析越界而导致该 JSON 字符串泄露并错误打印到屏幕上。

# 10. 风险与已知不确定点

- **AIOps 断线机制**：普通的 `/api/ai_ops` 是一次性长链接。若模型响应时间意外超过 Frontend 的 Axios 超时配置，将在前台留下错误的警告状态；目前采取延长至 `300,000` ms 进行兜底防范。

# 11. 非目标

（同 3，再次强调）不触碰 Go 后端底层的大模型推理链结构。
